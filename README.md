# Английский A2 → B2: комплект скилов для Google AI Edge Gallery

| Скил | Тип | Зачем |
|---|---|---|
| **english-coach** | текст | тест уровня, маршрут A2 → B1 → B2, план на день и неделю, контрольные точки |
| **english-tutor** | текст | 13 методик: проверка текста, грамматика, чтение, обратный перевод, пересказ, ролевые сценки (быт и геодезия), разбор речи из Audio Scribe, метод 4-3-2, письмо, коллокации, сбор фраз, работа над ошибками, тесты |
| **vocab-trainer** | JS | интервальные повторения (Leitner), 7 колод (~190 карточек), журнал ошибок, статистика и серия дней, карточки-перевёртыши |

## Колоды vocab-trainer
- `daily-a2` — быт, базовые слова (30)
- `daily-b1` — быт, шире и точнее (30)
- `phrasal` — фразовые глаголы (25)
- `survey` — геодезист, общие термины (35)
- `work-talk` — фразы для объекта и заказчика (20, с русского на английский)
- `linkers` — связки B1–B2 (20)
- `irregular` — неправильные глаголы, 3 формы (30)

Свои слова добавляются фразой «добавь слово to measure — измерять».

## Установка

### Текстовые скилы (coach, tutor)
Edge Gallery → Agent Skills → менеджер скилов → импорт из локального файла → выбрать `SKILL.md` из папки скила.

### JS-скил (vocab-trainer)
JS-скилы нужно положить на нормальный хостинг. Ссылки `raw.githubusercontent.com` не подойдут, потому что отдают файлы как text/plain. Самый простой вариант — GitHub Pages:
1. Создай репозиторий, например `english-skills`, и залей туда всю папку `vocab-trainer/`.
2. Положи в корень репозитория пустой файл `.nojekyll` (он уже лежит в архиве).
3. Settings → Pages → Deploy from branch → `main` / root.
4. Проверь в браузере, что `https://<ник>.github.io/english-skills/vocab-trainer/SKILL.md` открывается текстом.
5. В Edge Gallery: импорт по URL → вставить эту ссылку.

Текстовые скилы можно залить туда же и тоже ставить по URL.

## Как заниматься
1. «Определи мой уровень» (coach)
2. «Загрузи колоды daily-a2 и irregular» (trainer)
3. Каждый день: «Что делать сегодня? У меня 30 минут» (coach) → по плану: «повторим слова» (trainer) и упражнение (tutor)
4. Раз в 4 недели: «контрольная» (coach)

## Важно
- Прогресс хранится в памяти webview на телефоне. Сохраняется ли он после перезапуска приложения, нужно проверить. Пока не убедишься, раз в неделю говори «сделай export» и сохраняй строку в заметки.
- Маленькая модель иногда ошибается в тонкой грамматике, поэтому спорное лучше перепроверять.
- Произношение проверяется только косвенно: наговори фразу в Audio Scribe, вставь расшифровку в tutor и спроси «разбери мою речь». Если слово распозналось неверно, значит, произношение стоит подтянуть.
